# 资审工作台、京麦书面闭环与 v3 真实语音交付

原页面缺少工作人员任务上下文和书面回写闭环，新工作台又因独立进程关闭实时配置、未载入供应商凭据、共享 Cookie 和恢复文字会话而无法正常发起 WebRTC。本分支保留第一版三栏界面，复用后端 RoutingPolicy、身份守卫与持久状态，完成工作人员投影、权威书面预览/幂等执行/回写、未接通分流，以及专用 v3 真实语音启动和恢复接线。

审核知识与原件映射支持 6/68 个发布场景（3 电话、6 书面），11 个合成任务；身份核验前商家不可见具体品牌或驳回原因。语音采用真实原生音频理解 → 受控业务门面 → 已审核片段 → 流式 TTS → WebRTC，保留统一取消生命周期。专用 13000/18000 启动脚本隔离 Cookie、核对生产代理、保留原数据库和预算，并关闭语音业务写入。原始私有 ZIP、审核包、密钥、音频和原始日志均不提交。

验证：517 项后端通过，TypeScript 通过，Webpack 生产构建通过，5 项浏览器通过；数据库 10 操作/10 效果/10 回写 = 9 次模拟驳回 + 1 次跟进，9 个申请闭环。完整 v3 真实浏览器语音覆盖开场、明确身份、已审核 QA、不保证通过、语音打断和刷新重连。

**性能验收未通过，保持 Draft**：最终 30/36 有效轮次，P50 2077.8ms、P95 5323.2ms，6 个失败全部保留（4 次旧脚本播完等待超时、1 次客户端中断、1 次真实 TTS 超时）。结束检测返回和 TTS 尾延迟是本次主要瓶颈，业务审核 P50 62ms。不能宣传 P50 已低于 2 秒。比较元数据一致，但跨日 WAN 与成功案例配比不同，限制已写入报告。

语音自动关单未通过：没有独立可信播放证明，VOICE_WRITES_ENABLED=false；文字/京麦闭环与真实语音是独立证据。62 场景、真实电话联系事件、真实京麦、公网/TURN、物理设备人工验收、多实例容量和官方评分仍未完成。未部署、未修改 main 或线上数据库。
