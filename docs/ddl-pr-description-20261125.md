# 资审工作台、v3实时语音与定向时延优化（保持Draft）

工作台复用RoutingPolicy、身份守卫和持久状态，完成工作人员投影、权威书面预览、幂等模拟执行/回写及未接通分流；恢复专用13000/18000真实WebRTC、Cookie隔离、生产代理核对与匹配媒体会话。知识支持6/68个场景（电话3、书面6），11个合成任务；未发布内容不自动启用。

本轮仅做定向性能修复：VAD 400/300/250受控配置（默认400/0.5）；有界、默认关闭的高精度帧/队列/WS/HTTP诊断；可选200ms有界SSE尾部读取，使现有TTS AsyncClient实际复用连接。未重新构建连接池、业务状态机或前端。修复观察到的开场前挂断KeyError，不伪造turn/generation或业务效果。

验证：534项后端、5项浏览器回归通过。10操作/10效果/10回写=9次驳回+1次跟进，9个申请闭环；这与真实语音是独立证据。真实固定三案例、已审核答案和播放期间语音打断通过；长自然停顿仍失败，不降低身份及绑定守卫，因此不采用300ms，250ms未上线。

**主要目标未达到：** 最终400ms+TTS候选固定每案例10个有效轮次，P50 2112.2ms/P95 2836ms。正式文件保留3次开场前失败，共30/33、9.09%；其中续测冻结版本23c7928为30/31、3.23%，此前2次失败依然保留。相比上一轮v3 P95下降约46.7%，P50未改善，旧基线P95的110%及整体门槛仍未通过。逐帧记录器开销未单独量化、跨时间WAN不受控，不作单一因果归因。

共享预算经两次明确确认从20/62/100增至24连接/74预留轮次/100TTS，实际24/74/91，旧14/42/50账本未变。原件、审核包、密钥、原始帧级日志和音频不提交。VOICE_WRITES_ENABLED=false，可信播放及自动语音关单仍未验收。

当前启动保留400ms原行为；候选需显式-TtsTailDrain。没有部署公网，没有改main或线上数据库。完整评审入口docs/ddl-latency-optimization-20261125.md；逐样本、各变体、最终时延、正确性、浏览器及预算机器证据均在该文档链接。
