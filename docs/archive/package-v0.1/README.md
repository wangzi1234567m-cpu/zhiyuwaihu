# 智语外呼架构与模块对接设计

设计版本：0.1.0。日期：2026-11-16，时区 Asia/Shanghai。适用对象：王梓恒、魏鼎承、翟雯。目标节点：2026-11-22 校赛答辩。

采用 Next.js＋TypeScript、FastAPI 模块化单体、显式状态机、PostgreSQL，语音优先采用声网 RTC＋对话式 AI 引擎，DeepSeek 经模型适配层调用。首版只实现模拟套餐变更；离线 RSI 只生成和选择 Prompt／话术候选，核心权限及订单规则由代码固定。

最先解决公网 HTTPS 回调、会话映射和取消链路。三人从第一天按同一契约并行开发，每天跑一次真实模块连接。未获得官方资料前，合成业务规则显式标记 `mock-v1`；它们不是官方业务规则。

## 阅读与执行顺序

1. 三人一起看 [需求与验收](01-requirements.md)、[架构](03-architecture.md) 和 [契约](05-contracts.md)，确定跨模块边界。
2. 王梓恒先落实 [技术决策](02-decisions.md) 与声网接入验收；魏鼎承按 [状态机](04-state-machine.md) 实现文本业务；翟雯按契约实现前端和 Mock。
3. 数据统一依 [数据设计](06-data.md)；交付时间依 [集成计划](07-integration.md)；评测与优化依 [指标与 RSI](08-evaluation-rsi.md)。

## 已定决策

| 项目 | 本版决策 |
|---|---|
| 权威状态 | 后端数据库；前端、模型和声网历史都不能覆盖业务事实 |
| 数据库 | PostgreSQL 主路径；SQLite 只作受控降级，不维护两套正式存储 |
| Agent 编排 | 普通 Python 状态转移函数＋工具守门；首版不引入 LangGraph |
| 语音模式 | 浏览器点击开始，AI 主动自报身份；只采集音频 |
| 通信 | RTC 音频；HTTP 控制；SSE 推送业务事件；声网兼容 Chat Completions SSE |
| 字幕 | 语音会话仅声网工具包 RTM 字幕流；文本模拟会话仅后端 SSE，二者互斥 |
| 取消 | 声网停止播放＋后端取消可取消任务＋generation 标记隔离晚到事件 |
| 订单 | 后端确认记录绑定不可变报价；提交 operation 固定幂等键；未知结果查证 |
| 日志 | DB 保存审计事实，脱敏导出评测证据；Langfuse 可选异步派生视图 |
| 版本 | 每个会话固定 strategy_version；采纳／回滚只影响新会话 |

## 当前证据边界

本轮完成的是设计与结构样例，不代表功能已实现。没有应用依赖锁文件，没有账号调用、性能实测或部署验证。包仓库核查记录在 [dependency-research.json](dependency-research.json)，它是候选版本快照，不是安装锁文件。资源已有一部分，用户稍后补充；影响选型的未决问题集中在 [来源与待确认](09-sources-open-questions.md)。

附件里的示意代码不作为实现依据：前端生成权威会话、信任 `user_confirmed=true`、泛化 HTTP 工具入口、自动修改守门规则、把首 Token 当端到端语音时延等做法均已纠正。文档中的建议目录仅在开始实现时采用，不预建整套应用空壳。
