## 问题与修复

否定作用域原先会把“我没空请回电”“我不能等了要投诉”里的否定词扩散到后面的真实诉求。增量修复按同一分句中的触发位置区分直接否定、正反问、双重否定、被迫式和自身状态描述；后续明确请求保留，更近的“不要/不用”等否定仍生效。宿主审查另发现“又不能”被误列为双重否定以及漏掉“不必”，已由 GLM 最小修复并新增四条反例回归。原生审查随后指出“不想/不愿”的情态否定遗漏，已由 GLM 在触发前缀末尾增加受限识别，避免向整个窗口粗加裸“不”；同时去掉“再”作为独立新请求标记，保留“没空再回电”的否定。后续复审要求保留“并非不想/绝非不愿意”的双重否定，已在直接否定和情态否定前识别，并补充单层“并非/绝非”反例。宿主审查将“愿意”的意字设为可选并复用现有窗口常量。没有新增审核权限、工具白名单、路由阈值或自由生成回复。

这些规则是有限的汉语表达家族覆盖，不能据此宣称任意转写文本都能准确理解。回归句子已向开发暴露，不能充当 RSI 独立保留集或对外准确率。文件哈希记录宿主 Windows 测试目录的原始字节；Git 归档可能按属性规范化换行，归档内文件哈希以交付清单为准。
