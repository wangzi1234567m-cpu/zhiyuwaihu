# feat(agent): 接入结构化理解、业务守卫与RSI评测，修复否定作用域

在0.3骨架上接入Agent/Policy/Guard和RSI。三轮文本会话可以核对身份、解释已发布驳回原因、回答风险问题，再由协调器执行模拟业务并回写。前端显示后端权威状态，刷新恢复记录。
